# PEIM AI 复现指南（实现规格与验收）

版本标识：**v0.1**（当前发布版本）
项目：PEIM —— WinPE / Windows 桌面用的极简全拼中文输入法（含英文模式补全）

> 本文是**实现契约**：按本文从零实现，应能通过第 10 节验收矩阵。
> 项目结构、模块职责和修改指引见 [README.md](../README.md)。

## 1. 背景与目标

目标环境 **WinPE 10.0.19041 / zh-CN / x64**（ADK 2004 生成的 PE）没有可用的第三方中文输入法：

- 无 `ctfmon`、无 TSF 输入法
- user32/imm32 **不加载第三方 IMM32 IME**（实测 `ImeInquire` 从不被调用、`ImmInstallIME` 失败）

因此本项目采用 **全局键盘钩子 + Unicode 文本注入** 的方式实现一个"够用"的输入法。

**目标**

- PE 内可输入常用中文（单字 + 二字/三字/四字词），不丢键、不卡死、界面极简
- 中文态可回头打英文原文；英文态可正常输入英文并获得常用词补全
- 不依赖注册表/驱动；需要管理员权限（普通用户启动时自动 UAC 提权）；复制文件即可运行，删除文件即可卸载
- 默认英文态，避免 PE 菜单/工具的单键热键被吞

**非目标**

- 不做云输入、用户词库、词频自学习、皮肤、设置界面
- 不做双拼/五笔/手写/语音
- 不提供 PE 镜像注入/安装脚本（只交付运行文件，部署方式由使用者决定）

## 2. 运行环境约束（硬性）

| 项目 | 要求 |
|---|---|
| 操作系统 | WinPE 10.0.19041 zh-CN x64；同时兼容 Windows 10/11 桌面 |
| 架构 | **仅 x64** |
| 权限 | **需要管理员权限**；普通用户启动时自动 UAC 提权，取消则退出 |
| 系统修改 | **不写注册表、不装服务/驱动、不改系统目录**；安装=复制文件，卸载=删除文件 |
| 依赖 | 只用 Windows 自带 DLL；静态链接，无第三方运行时；EXE 不依赖 VCRuntime |
| 输入法框架 | 不使用 IMM32/TSF（PE 不支持） |
| 运行方式 | 后台进程，无主窗口；有 Explorer 时显示托盘图标，无 Explorer（PE）时显示右下角状态方框 |
| 磁盘 | PE 的 `X:` 是内存盘，重启清空；日志必须限容轮转 |

## 4. 功能需求（FR）

### FR-00 运行方式与状态显示
- 无需安装：四个运行文件放在同一目录，双击/命令行启动。
- 有托盘：托盘图标显示中/英（两者均为蓝底白字，背景色 `#0060AC`），左键单击切换，右键菜单可切换/退出。
- 无托盘（WinPE）：屏幕右下角状态方框显示中/英（同样蓝底白字），左键单击切换，右键菜单可切换/退出。
- 界面始终反映当前中/英状态。

### FR-01 启动与单实例
- 启动后读取 EXE 同目录的 `peim_cn.dict`、`peim_en.dict`（可选）与 `peim.ini`，打开 `PEIM.log`，安装全局键盘钩子。
- 同一用户会话只允许一个实例（命名互斥体 `PEIM_HOOK_SINGLE_INSTANCE`）；重复启动直接退出。
- 词库缺失/损坏时不得崩溃：中文退化为原文直输，英文可正常输入；日志记录错误。
- 低完整性进程（从 Low 标签目录启动）无法向普通程序注入：检测到后提示并退出（退出码 4）。
- 正常模式启动时检查管理员/提权状态：若不是已提权管理员，则用 `ShellExecuteExW("runas")` 启动自身并退出；
  UAC 被取消时提示并退出（错误码 5）。
- 支持 `--selftest`：初始化配置/日志/词库/候选窗后退出（0=正常，3=词库失败），
  **不安装键盘钩子、不弹窗报错、不尝试提权**。

### FR-02 中/英模式
- **默认英文态**（`start_cn=1` 可改为默认中文）。
- **单击 Shift** 切换中/英；Shift 与其它键组合（Shift+字母、Shift+Tab…）不触发切换。
- 切换后候选窗短暂显示"中"/"英"提示（约 0.9 秒）。
- 中文态拦截字母键；英文态字母/数字等照常放行（英文联想除外）。
- 退出：托盘/右下角方框的右键菜单；不设退出快捷键。

### FR-03 全拼组字与候选
- 中文态下字母（含 Shift+字母）追加到输入缓冲，内部用小写解析、原文保留大小写；**最多 32 个字母**。
- 每输入一个字母都重新解析并刷新候选窗。
- 解析：输入串切成合法音节序列 + 可选尾部"未完成音节"（尾部必须是某合法音节的前缀）。
  切分使用**音节权重 + 动态规划**，规则见第 6 节。

### FR-04 音节候选
- 当输入包含完整音节时，列出音节序列匹配的词条（词条音节数 ≤ 已输入音节数，且逐音节相等）。
- 排序：覆盖音节数多者优先 → 同覆盖数按词库 `weight` 降序。

### FR-05 前缀候选（首字母/未完成拼音即可选词）
- 对整个输入串做字符级前缀匹配：词条拼音串（各音节名直接拼接）以输入串开头。
- 音节数上限 `max_syl = 完整音节数 + (存在未完成音节 ? 1 : 0)`：
  `c`/`zh` 只出单字；`zhongg` 只出二字词；`zhongguo` 不出三字词；`zhongguod` 才出三字词。
- 排序：按 `weight` 降序；选中时吃掉整个输入缓冲（提前上屏）。

### FR-05b 整串完全匹配优先
- 先挑出拼音串与整串输入完全相同的词条（如 `fangan`→方案、`yange`→严格、`huanying`→欢迎），
  按 `weight` 降序排最前，避免被音节切分歧义埋没。

### FR-06 简拼
- 输入长度 2~4 且全小写，并满足以下任一条件：
  1) 整串不是合法拼音（`rc<0`，如 `ck`、`cxy`、`cpgl`）；
  2) 能解析，但所有完整音节都是 `n`/`m`/`ng`/`hng` 这类非标准音节（如 `nh` 被解析成 `n` + 尾部 `h`）。
- 匹配：`entry.syl_count == 输入长度`，且每个音节首字母依次等于输入字符。
- 按 `weight` 降序；选中时吃掉整个缓冲；音节候选与原文候选依次放在后面。

### FR-07 候选拼接顺序（中文态）
| 情况 | 顺序 |
|---|---|
| 解析失败 | 原文候选 |
| 解析失败但命中简拼 | 简拼候选 → 原文候选 |
| 首字母大写（解析成功） | 原文候选 → 整串匹配 → 前缀候选 → 音节候选 |
| 纯完整音节（有音节候选） | 整串匹配 → 音节候选 → 前缀候选 |
| 有未完成音节（tail） | 整串匹配（通常无）→ 前缀候选 → 音节候选 |
| 解析成功但无完整音节（`z`） | 整串匹配 → 前缀候选 |

- 同一词条（相同音节序列 + 相同文字）只出现一次；总候选上限 200。

### FR-08 分页
- 每页候选数由 `page_size` 决定（默认 5，范围 3~9）。
- 候选条显示页码 `当前/总数`。
- 键盘翻页：`-` / `PgUp` / `=` / `PgDn`；数字 `1`~`9` 选中当前页第 n 项。
- 候选条尾部显示 ▲/▼ 按钮，鼠标点击翻页；点击不得抢走目标窗口焦点。
- 翻页（键盘或鼠标）只刷新候选与页码，**不改变候选窗位置**。

### FR-09 选词与上屏
| 操作 | 行为 |
|---|---|
| 数字 1~9 | 上屏当前页对应候选（无候选时放行给应用） |
| 空格 | 有候选→上屏第一项；无候选但有输入→原文上屏；否则放行 |
| 回车 | 有输入→原文上屏（不执行命令）；无输入→放行（用于 cmd 执行） |
| Esc | 有组字/候选→清空并隐藏候选窗；否则放行 |
| 退格 | 有输入→删除最后一个字母并刷新；否则放行 |

### FR-09b 英文直输（中文态）
- 字母（含 Shift+字母）一律进入缓冲，不因"不是合法拼音"被丢弃；缓冲最多 **32** 个字母。
- 当整串无法解析成拼音，或首字母为大写时，候选第一项 = 用户输入原文（保留大小写）。
- 原文候选被选中（空格/回车/数字 1）时注入原文并清空缓冲。

### FR-09c 英文模式单词补全
- 英文态下字母照常输入（不吞键）；最近输入的字母（1~32 个，第一个字母就开始）作为前缀查询 `peim_en.dict`。
- 有匹配时在候选窗显示补全候选（第一行是已输入字母 + 闪烁光标，第二行是候选）。
- 排序：短词优先（词长升序）→ 同长度按词频降序。
- `1`~`9` 或 Tab 选择：先对已输入字母发退格，再注入完整单词；首字母大写则保留大写。
- 空格/回车/标点/方向键结束联想并正常输入；切换窗口或切换中/英时清空联想。
- 配置 `en_suggest=0` 可关闭；`peim_en.dict` 缺失时自动退化为普通英文输入。

### FR-10 标点
- 中文模式固定转换主键盘符号键：
  - 数字行 Shift：`! @ # $ % ^ & * ( )` → `！＠＃￥％＾＆＊（）`
  - 标点键：`,` `.` `;` `:` `?` `/` → `，。；：？／`；Shift+`,`/`.` → `《》`
  - 括号/引号：`[ ] { }` → `【】｛｝`，`\ |` → `、｜`，反引号/波浪号 → `｀～`
  - 单引号/双引号成对输出：`‘’` / `“”`
  - 空闲时 `- _ = +` → `－＿＝＋`；候选列表显示时 `-`/`=` 仍用于翻页
- 英文模式：标点按键盘原样输入。
- 无配置项；组字中先上屏当前候选/原文，再注入标点。

### FR-11 候选窗
- 自绘 GDI 无边框小窗：白底、1px 灰边、宋体（`font_height` 像素高，默认 16）。
- 布局：**两行**。第一行显示拼音/字母串 + 末尾闪烁输入光标（约 500ms 亮/灭）；
  第二行显示 `1.候选`… → 页码 → ▲/▼。候选区开头不显示中/英模式字。
- 切换中/英时的提示：单行居中显示 中/英，短暂出现后隐藏。
- 窗口样式必须 `WS_POPUP | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_TOPMOST`：不抢焦点、不进任务栏、始终可见。

### FR-12 定位
- 优先跟随插入符（`GetGUIThreadInfo` 的 `hwndCaret` + `ClientToScreen`），显示在插入符下方 6px。
- 拿不到插入符时跟随鼠标，显示在指针下方约 16px。
- 超出屏幕边缘时向内收（底部放不下时翻到上方）。

### FR-13 日志
- 位置：EXE 同目录 `PEIM.log`（环境变量 `PEIM_LOG_DIR` 可覆盖，测试用）。
- 记录：启动/词库统计/钩子安装/模式切换/上屏/英文替换/退出/错误。
- `log_verbose=1` 额外记录每次按键与每次候选列表。
- 日志超过 512 KB 自动轮转为 `PEIM.log.old`。

### FR-14 配置
- EXE 同目录 `peim.ini`（环境变量 `PEIM_INI` 可覆盖，测试用），键值见 §7.3。
- **`peim.ini` 不存在时自动生成默认配置文件**（UTF-8 BOM + 中文注释，方便用记事本编辑）。
- 所有键可选；未知键忽略；解析失败用默认值。

### FR-15 部署
- PE 内落盘目录由使用者决定（示例：`X:\Tools\PEIM\`），复制运行文件后手动启动 `PEIMH.EXE`。
- 是否加入 PE 开机启动由使用者自己的 PE 启动流程决定；本仓库不修改 boot.wim / startnet.cmd。
- 桌面 Windows：复制文件到普通目录（如 `%LOCALAPPDATA%\PEIM`）后双击运行；删除文件即卸载。

## 6. 候选生成算法（可据此重写）

输入：`raw`（原样，含大小写）、中文词库。

1. `lower = lowercase(raw)`，最多 32 个字母。
2. **解析** `lower`：
   - **音节权重**：每个音节取"该音节下最高频单字"的 `weight` 作为分值。
   - 动态规划：`dp[pos][k]` = 用 k 个完整音节覆盖 `lower[0:pos)` 的最大总分
     （音节长度 1~6，查音节表）。然后：
     1) 若整串能完全切分：先选**音节数最少**的方案（长音节优先），
        音节数相同时选平均权重最高的（总分/k）；
     2) 否则从后往前找最长的可切分前缀 `cut`，剩余 `lower[cut:]` 若是某音节前缀则作为
        `tail`（未完成音节）；
     3) 仍失败 → 解析失败（`rc=-1`），`nsyl=0`。
   - 例：`zhonghuarenmingongheguo` → `zhong|hua|ren|min|gong|he|guo`。
3. **整串完全匹配候选**：拼音串与 `lower` 完全相同的词条，按 `weight` 降序，排最前。
4. **音节候选**：音节序列是已解析音节序列前缀的词条；`consumed` 降序 → `weight` 降序。
5. **前缀候选**：`entry.pinyin_string.startswith(lower)`，`syl_count <= max_syl`，按 `weight` 降序；
   这类候选吃掉整个缓冲。
6. **简拼候选**：规则见 FR-06。
7. **原文候选**：`rc<0` 或 `raw[0]` 为大写字母时生成；简拼命中时原文排最后。
8. **拼接/去重**：按 FR-07 顺序拼接；同一词条只出现一次；总候选上限 200。
9. 每页显示 `page_size` 个；页码从 1 开始。

**上屏语义**

- 原文候选：注入 `raw`，清空缓冲。
- 整串/前缀/简拼候选：注入词条文字，清空整个缓冲。
- 音节候选：注入词条文字，删除该候选覆盖的音节对应字母，剩余输入重新解析。

## 7. 数据格式

### 7.1 中文词库 `peim_cn.dict`（小端）

```
u32  magic = 'PEIM' (0x4D494550)
u16  version = 1
u16  syllable_count
u32  entry_count
音节表: syllable_count × { u8 len; char name[len]; }        # 小写 ASCII，按字典序升序
词条表: entry_count × {
    u8   syl_count             # 1..8
    u16  syl_ids[syl_count]    # 音节表下标
    u16  weight                # 1..65535，越大越靠前
    u8   text_len              # 1..8（UTF-16 单元数）
    u16  text[text_len]        # UTF-16LE
}
```

- 内容：单字（GB2312 全集，多音字按读音入条）+ 二字/三字/四字词；
  当前约 **415 音节 / 70,130 条 / 920 KB**（二字 40,000、三字 15,000、四字 8,000）。
- `weight` 由 `tools/words2dict.py` 生成：优先 wordfreq 通用词频（zipf 映射到 1..65535），
  缺数据时退回 jieba 词频；领域词固定 65535。
- 多音字：主读音保留；次读音只有在常用词中有使用证据（或属于常见读音白名单）时保留，
  权重按证据比例缩放，避免 `neng→而`、`zi→事` 这类生僻读音抢常用字。
- `lve/lue`、`nve/nue` 两种输入习惯都会生成条目。
- 音节表按字典序排列（二分查找依赖）。
- 生成脚本：`tools/words2dict.py`（jieba + pypinyin + wordfreq + `tools/words/cn_words_curated.txt`）。

### 7.2 英文词库 `peim_en.dict`（小端）

```
u32 magic 'PEEN'
u16 version = 1
u32 count
u32 offsets[count]      # 相对词条区起点的偏移
词条区（按词字典序升序）：u8 len + ASCII 小写词 + u16 weight
```

- 当前 **10,007 词 / 133 KB**：Google 10k 常用英文词 + 领域补充词（`tools/words/en_words_curated.txt`）。
- 生成脚本：`tools/words2dict.py`；`peim_en.dict` 缺省时英文联想自动关闭。

### 7.3 配置 `peim.ini`

| 键 | 默认 | 取值 | 说明 |
|---|---|---|---|
| start_cn | 0 | 0/1 | 启动即中文；默认英文，保证 PE 菜单/工具按键不被吞 |
| page_size | 5 | 3~9 | 每页候选数 |
| font_height | 16 | 10~40 | 候选窗字体像素高 |
| en_suggest | 1 | 0/1 | 英文模式单词补全 |
| log | 1 | 0/1 | 写 PEIM.log |
| log_verbose | 0 | 0/1 | 记录按键 + 候选列表（调试） |

## 8. 非功能需求

- **稳定性**：连续快速输入不丢键、不卡死；钩子回调只做纯计算 + 投递消息，不调用阻塞 API。
- **内存/体积**：EXE 约 79 KB；中文词库约 920 KB、英文约 133 KB；
  运行时私有内存约 4 MB、工作集约 12 MB（x64，开发机实测）。
- **性能**：单次按键到候选窗刷新为毫秒级（词库 7 万条；无硬性 SLA）。
- **安全/隐私**：不联网；不读用户文档；不写系统目录/注册表；日志只写自身目录。
- **可维护性**：C99、单线程、模块边界清晰；关键决策有注释。
- **可测试性**：拼音核心可脱离 Windows 单测（`build\ptest.exe`）；程序支持 `--selftest`。

## 9. 构建与测试

工具链：仓库不直接携带编译器；首次构建时如果 `tools\w64devkit` 不存在，
`build_all.cmd` 会自动调用 `tools\get_w64devkit.ps1` 下载 w64devkit 2.11.0（GCC 16.2.0）。
也可以先手动运行：

```cmd
powershell -ExecutionPolicy Bypass -File tools\get_w64devkit.ps1
```

编译选项：`-O2 -Wall -Wextra -std=c99 -DUNICODE -D_UNICODE -mwindows -static -static-libgcc -s`。

**每次构建都需要 Python 3.8+**（构建脚本会检查，没有则直接报错）：

```cmd
pip install jieba pypinyin wordfreq
```

```cmd
build_all.cmd    rem 每次都会：重新生成中英文词库 → 编译 PEIMH.EXE / ptest.exe

build\ptest.exe build\peim_cn.dict zhongguo nihao jisuanji    rem 核心测试
build\ptest.exe build\peim_cn.dict -s 2 zhongguo              rem 选中第2个候选并看上屏
build\PEIMH.EXE --selftest                                    rem 部署自检
```

运行时不依赖 Python 和第三方库。

## 11. 不在范围 / 已知限制

- 不做双拼/五笔/手写/语音、云词库、用户词库、词频自学习、五字以上词条、皮肤/设置界面。
- 仅 x64；不支持 32 位 PE、Windows 7 及更早。
- 依赖目标控件处理 `WM_CHAR`：XAML/TSF 界面（Win11 任务栏、开始菜单、新版资源管理器）不接收这种注入；
  PE 环境没有这些组件，不受影响。
- 管理员窗口（UIPI）：本程序已整体以管理员运行，因此可向管理员窗口注入；部分自绘控件（Qt/Electron）可能无效。
- 英文联想候选显示时，数字键 `1`~`9` 用于选词（先结束联想才能输入数字）。
- 长句为"音节切分 + 整词优先"，不是完整语言模型；极端歧义拼音可能不是最理想切分。
- 与系统自带输入法共存时，Shift 会同时切换两边；**不要同时把 Microsoft Pinyin 和 PEIM 都设为中文**。\n  两个中文 IME 会同时处理符号键，可能出现符号重复/异常；使用 PEIM 时把系统输入法设为英文或关闭。
- 托盘图标在 Explorer 重启后不会自动恢复（重启输入法即可）。

## 12. 第三方与许可

- 运行时 EXE 只依赖 Windows 系统 DLL，不链接第三方库（仅静态链接 MinGW-w64 启动代码）。
- 词库生成使用：jieba（MIT）、pypinyin（MIT）、wordfreq（Apache-2.0）、
  google-10000-english（仓库未声明明确许可）、w64devkit（宽松许可，构建前由脚本下载）。
- 许可全文在 `tools/licenses/`；分发词库数据时请保留该目录。
- 若对 google-10000-english 许可有更严格要求：删除 `tools/words/en_words_freq.txt`，
  仅用 `tools/words/en_words_curated.txt` 重新生成英文词库，或不分发 `peim_en.dict`。

## 13. 从零重建的推荐顺序

1. **词库工具**：`tools/words2dict.py`（一次生成 `peim_cn.dict` 与 `peim_en.dict`）
2. **核心库**：`peim_dict`（零拷贝读 + 遍历 + 音节二分查找）、`peim_pinyin`（DP 切分/候选/提交），
   用 `ptest` 验证 `zhongguo`/`nihao`/`jisuanji`/长拼音
3. **主程序**：钩子 → 状态机 → 候选生成（整串匹配/音节/前缀/简拼/原文）→ 注入队列
4. **候选窗**：两行布局、定位、▲/▼ 点击、闪烁光标
5. **英文联想**：词库读取、前缀查询、退格替换注入
6. **配置/日志/自检/单实例/低完整性检测**
7. **验证**：按第 10 节矩阵在桌面与 PE 实机逐项测试
